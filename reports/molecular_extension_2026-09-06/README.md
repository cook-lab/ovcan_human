# Expanded molecular characterization

6 September 2026. This extension follows the author's request to pursue reasonable analyses beyond CCNE1 and prepare actionable cluster work. Four coordinated analyses use the existing data without modifying the canonical matrices, 6,194 coding candidates, manuscript v9 or validated 49-file release. Related sublines remain linked to their patients.

## Main conclusions

1. **AKT2 in OV3331 is a strong new concordant lead.** Its gene segment log2 ratio is 2.964 and the median across six positive gene-overlapping target bins is 3.219, with a large local-versus-arm contrast. It has the highest AKT2 RNA (1,177.011 TPM) and second-highest protein abundance of 31 measured models. This supports focused copy-number/amplicon validation and model selection; absolute amplification has not yet been measured.
2. **NF1 and CDKN2A merit targeted deletion review.** NF1 has deep canonical-exon depletion in TOV2835EP and complex/partial depletion in related TOV3121D/TOV3121EP. CDKN2A has near-absent target coverage in the 1369 pair and partial dropout in TOV2414. Five recovered normal coverage files support capture of the affected bins. Zero-depth and partial-locus patterns are explicitly retained; whole-gene homozygous deletion and protein loss are not inferred.
3. **Useful expression leads extend beyond HER2/FRalpha.** Stable joint RNA/protein leaders include ERBB2/TOV3392D, SLC34A2/VOA12539, CDH6 and VTCN1/OV3331, and CD276/VOA8762. FOLR1/OV2295 is a particular model lead: averaging its related sublines moves patient 2295 to rank 8. ESR1 and several chromatin proteins show discordance that makes RNA alone an unreliable substitute for their supplied protein values.
4. **Exact read evidence changes how several variants should be interpreted.** All 65 selected candidates match their archived alleles; indel AF is recovered for 24 records. Adjacent ATM calls in OV2295 and TP53 calls in TOV2881EP share local phase groups and require combined-haplotype review. They should not be counted as independent hits. Stronger leads such as BRCA2/TOV81D, BRAF/OV90, and CDK12 in the 3133 family/OV3291 retain separate read, biological and clinical-assertion fields.
5. **The existing SBS data do not support a robust SBS3-positive classification.** Across target-opportunity-adjusted full-dictionary fits, every model's 95% bootstrap range includes zero, under both the baseline and stricter read/population screens. Restricted dictionaries sometimes assign substantial SBS3, but that support does not persist with the full dictionary. This is evidence of fitting uncertainty, not evidence that all models are HR-proficient. Credible allele-specific genomic scars and MSI need alignment-derived inputs on the cluster.

The gene-CN research screen yields 41 model–gene gain rows and 15 loss rows. Of 1,196 WES model–gene rows, 1,074 meet the screen's complete-span/positive-bin eligibility criteria; 122 do not. These counts are not independent-patient prevalence or clinical calls. Broad events can affect several genes at once, and deeply depleted loci can lack enough positive bins for the strict screen while remaining high-priority review candidates. WES-available and screen-eligible denominators are separate.

No value is imputed for a missing modality. RNA/protein each cover 31 models, 30 are paired and 13 models have all three modalities. RNA still uses Ensembl release-93 quantification; newly pinned GRCh38 DNA annotations do not replace it. Protein units remain supplied log2 normalised abundance; isoDoping flags remain visible without automatic exclusion. The [prior clinical assessment](../clinical_classification_2026-09-06/README.md) and [CCNE1 assay review](../clinical_classification_2026-09-06/CCNE1_EXPRESSION_REVIEW.md) remain relevant.

## What to run or retrieve on the cluster

Start with [the new agent task](../../docs/cluster/molecular_extension_2026-09-06/AGENT_TASK.md). It contains prioritized tasks, explicit pilot models, input requirements, acceptance criteria and a return format. Companion [recipes](../../docs/cluster/molecular_extension_2026-09-06/RECIPES.md), [model aliases](../../docs/cluster/molecular_extension_2026-09-06/models.tsv), [locus requests](../../docs/cluster/molecular_extension_2026-09-06/locus_review_requests.tsv) and templates make it directly shareable with the cluster agent.

The first priorities are alignment eligibility and existing-result discovery; selected read/exon checks; a tumour-only MSI pilot; and suitable germline-SNP/mapping-bias inputs for an allele-specific CN pilot. The current Mutect2 VCFs did not retain an unbiased germline-SNP substrate. HRD-scar components are downstream of acceptable allele-specific fits. Callable-exome TMB, targeted RNA splice/fusion follow-up and upstream proteomics records are additional tasks with explicit prerequisites, not assumed local capabilities. Initial discovery does not submit jobs; the operator reviews proposed commands/resources before running pilots.

For a cluster agent using the public repository before these local changes are published, transfer the generated `output/cluster_handoff/ovcan_molecular_extension_tasks_2026-09-06.tar.gz` overlay and extract it into a working clone. Its README names the entry point, and its SHA-256 manifest verifies every included file. It carries small reports, processed candidate tables, templates and scripts; no raw alignments/sequence files or whole-exome VCFs. Preparing the overlay does not push the repo or run cluster jobs.
