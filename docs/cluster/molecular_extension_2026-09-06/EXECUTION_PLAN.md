## What the return changes

The cluster reports complete duplicate-marked GRCh38 CRAMs for all **23 models / 16 patients**, alongside interval-restricted recalibrated generations and the exact recorded CNV input chain. There are no existing eligible SNP inputs, MSI scores or allele-specific fits in the searched WES roots. These analyses need new bounded computation, not another broad search. All 23 returned source-CNR and target-only-CNR hashes agree with the local manifest; all 23 corrected CNS hashes also match the files in this checkout. See [integration and qualifications](../recovery/2026-09-06-molecular_extension/LOCAL_REVIEW.md).

The absence of model antitarget coverage is explained by interval-restricted CNV inputs. Complete alignments restore access to reads outside those intervals, subject to actual exome depth. The five public normals lack duplicate marking and BQSR and used bwa-mem2; same capture kit does not make them process-matched. Neither they nor the variant PoN are matched donor normals.

## Stage 1: resolve focused molecular leads and MSI

**MEX02/03/08 — focused read and exon review.** Use the complete md alignment, exact reference and the 30 variant requests. Merge overlapping windows only within the same model for extraction, while preserving all candidate IDs. Begin with combined haplotypes at OV2295 ATM and TOV2881EP TP53; then TOV81D BRCA2 and CDK12 loss candidates. Retain bases, qualities, full CIGAR, flags, mate information and relevant tags in local slices; the first nine SAM columns alone cannot establish sequence or haplotype support. Return fragment-level support for each component and combined allele, reference/alternate reads, strand/orientation, mapping/base quality, read position, soft clipping and repeat context. Compare with the archived VCF and explicitly explain differences. Reuse the completed exact ClinVar snapshot; no repeat external query is needed.

For MEX03, report both original capture intervals and the retained **204,706 CNV target bins**, with coordinates/overlap mapping. Calling intervals, split CNV targets and annotated exons have different denominators. Cover AKT2/CCNE1 boundaries, NF1, CDKN2A p16/p14ARF, CCND1 and ERBB2. Include zero-depth bases/bins and coding/UTR/isoform distinctions. Produce permissive and quality-filtered coverage (explicit MAPQ/BQ, duplicate/supplementary and overlapping-mate handling); do not equate `bedcov` depth sums or read counts with mean depth. Exclude CIGAR deletions/skips from the base-coverage measure. Keep copy-number/exon overlap and mappability exclusions explicit.

The existing five-normal CNNs are adequate for the immediate historical target-level comparison. New normal BAM coverage must be labelled as unmarked-duplicate coverage unless derived duplicate-marked copies are prepared; do not silently compare it with duplicate-excluded model depth. If normal preprocessing is undertaken for MEX05b, reuse those derived alignments for comparable focused depth. WES can support a depletion/amplicon interval without resolving an exact structural breakpoint or proving an absolute homozygous deletion.

**MEX04 — MSI.** Pilot TOV21G, TOV2414, TOV3392D and OV3331 with staged hg38 models, `-c 20`, four threads, and a complete model BAM/index temporarily materialized on node-local storage. Save conversion provenance and read-flag counts. Confirm the executable's duplicate/filter behavior; if undocumented, compare a declared primary-read, duplicate-excluded input on one high-yield sample before freezing the protocol. These four models are contrasts, not known assay controls.

Return the score plus modeled-site count, valid/evaluable-site count, unstable-site count, per-site distributions, depth and reasons for unavailable loci. Check contig/sequence compatibility and overlap with capture targets/flanks. On representative high/low scores, assess site-set/depth sensitivity (for example coverage thresholds 15/20/30) and report score uncertainty from site resampling as a stability measure, not biological replication or clinical calibration. Scale to 23 only if the command, site accounting and technical behavior are coherent; low or inconsistent site yield is indeterminate. No control alignments were found, so clinical MSI-H/MSS calibration remains unavailable even if all jobs succeed.

## Stage 2: SNP inputs and allele-specific CN

**MEX05 — five-model germline-inclusive input pilot.** Use TOV81D, OV2085, TOV2929D, OV3331 and OV1369-R2. Before the full five-model call, compare fixed population SNPs on-target and in 0–75 bp flanks between complete md and Oct-24 recal for one model (OV3331). Record depth, AD/BAF, MAPQ/BQ, overlapping-read handling and sample fingerprints. Investigate discordance rather than assuming these re-executed generations are identical. Retain the complete md input as the default; absent BQSR is a documented limitation. If quality behavior materially changes usable SNPs, recover the applicable recalibration table and propose a derived, properly padded recalibration; do not use padding on an already restricted BAM as a substitute for missing reads.

Run GATK 4.5.0.0 Mutect2 with the staged PoN/gnomAD resource, **both genotype-retention flags true**, calling BED and 75 bp padding. This is targeted input regeneration; do not realign reads or replace the retained somatic candidate set. Generate filtering companions and keep the complete FilterMutectCalls VCF, including non-PASS germline/PoN sites. Report sequential counts of candidate population SNPs, covered loci, retained SNPs, chromosome coverage and BAF distributions; show actual flanking yield rather than treating padding as measured territory. Failing the SNP-yield/identity/quality checks stops that model's ASCN interpretation.

**MEX06 — diagnostic fits.** Use `--tumor <target-only.cnr>` with matching corrected CNS exported to SEG and the new complete filtered VCF. Remove the draft's `--log-ratio-file <cnr>` and `--stats-file <Mutect2 .stats>`; they invoke incompatible parsers. Use `--model beta --model-homozygous --min-base-quality 20 --interval-padding 75 --post-optimize --out-vcf --seed 20260906`. Omit the unrelated calling-BED `--intervals` input. For the primary pilot use matching autosomal subsets of CNR/CNS/VCF, preserving original files and native ratio values; this avoids interpreting unresolved sex-chromosome reference offsets. Return excluded chromosome/bin counts and keep sex-chromosome conclusions unassessed.

Compare purity 0.30–0.99 with 0.80–0.99 while holding **ploidy 1.5–8 and `--max-copy-number 16` fixed**. If needed, compare max-copy settings 12/16 within the same purity/ploidy grid; the original two drafts changed three factors together. The maximum-copy option limits allele fitting, not the reported total-CN ceiling. Save all competing solutions and boundary hits; a best fit at a ceiling requires an expanded sensitivity or an unresolved result. Purity is a model parameter, not a measured fraction of malignant cells in culture.

Start with `--fun-segmentation none` for an imported-boundary diagnostic. PureCN can recenter imported segment means internally: preserve source means and record that transformation. Before LOH/scars, compare with **BAF-aware PSCBS** from the same bins and SNPs (verify installed dependency), because copy-neutral LOH breakpoints can be absent from total-CN segmentation. `Hclust` clustering of existing segments is an optional intermediate comparison and does not answer that problem by itself. PureCN's analysis must actually use the native CNR; record/fail any fallback to synthetic segment-derived ratios for purposes of native-bin/scar interpretation.

Fit acceptance requires interpretable BAF bands and target coverage, plausible competing solutions, total/major/minor CN consistency, explicit sex-chromosome handling, and locus/LOH conclusions stable enough across the grids and segmentation choices to state them. Keep accepted, ambiguous, failed and unassessed models separate. A numerical optimum alone is insufficient. If usable, expand the same protocol to the remaining 18 models. Prioritize repair-gene/deletion candidates and the related 3133/3121/1369 families for second-hit comparisons; aggregate by patient when summarizing frequencies.

**MEX05b — optional reference sensitivity.** If initial fits warrant it, prepare duplicate-marked *derived copies* of the five public normal BAMs in the new workspace, preserving original inputs and read groups. Run equivalent germline-retaining calls and build an AD-preserving multisample SNP input for mapping-bias estimation. Validate allele normalization, unique sample names, source AD preservation and missingness; never replace absent AD with reference support. The normal panel parser's use of AD does not by itself filter artifacts. This small, differently aligned panel is a sensitivity resource, not a process-matched reference or a source of matched-normal genotypes. Compare fits with/without its bias estimates. Five normals do not meet PureCN's default minimum panel size of ten normals for position-specific beta-binomial dispersion fitting; any `betabin` sensitivity must state what was estimated versus imputed.

If systematic coverage incompatibility prevents fitting, return that diagnosis. A small rederived-coverage comparison using complete model reads and consistently duplicate-marked normal reads is a possible rescue pilot; do not automatically replace the canonical CNV analysis or launch a cohort hybrid/off-target rerun.

## Stage 3: what credible fits can add

**MEX07:** pin scarHRD and report LOH, TAI, LST and their sum only for accepted allele-specific fits. Record GRCh38/centromeres, major/minor/total CN, fitted ploidy, excluded chromosomes/regions, gaps and genomic span versus directly covered target bases. Quantify alternative-fit and BAF-segmentation sensitivity. Reject/defer scar interpretation if copy-neutral LOH or broad boundaries are unsupported. These are exploratory exome-derived scars, with no commercial HRD cutoff, HR-proficient label for failures, or claim about current HR function. Standard WGS HRDetect/CHORD are not enabled by the recovered exomes.

**MEX08:** combine read credibility, current exact allele assertions, allele-specific CN and available RNA evidence for BRCA2, CDK12, ARID1A, SMARCA4, MMR and other selected genes. Do not infer a second hit from AF near one alone or count phased pieces as separate loss events. Historical TOV81D wild-type BRCA2 expression remains relevant context. Lack of a retained variant is not a callable wild-type result.

**MEX09:** optional sample-specific coding callability using explicit base/mapping-quality and duplicate/overlap handling. Existing mosdepth ≥20× summaries are coverage evidence, not by themselves a callable somatic denominator. Report usable coding Mb and limitations first. Only pursue TMB/signature updates if somatic-origin filtering is defensible; retain the current signature sensitivity report and never call 6,194 research candidates divided by kit size TMB.

**MEX10/11:** after locations arrive, inventory existing RNA alignments/junctions/fusions or FASTQs and the proteomics raw/PSM/reporter/configuration records. Verify stock/passages; OV3291 WES is not TOV3291G RNA. Preserve Ensembl-93 kallisto quantification; any new RNA alignment is a separate splice/fusion analysis. New lab-based HR, MMR, surface-marker, stock-authentication or drug-response evidence requires records or experiments.
