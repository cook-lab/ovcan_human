## Important context for execution

- Existing CNVkit results have four problematic antitarget bins. Current profiles use script 29's **target-only resegmentation**, followed by script 08 for descriptive centring. For an allele-specific pilot import matching target-only CNR/CNS in their native scale; do not pair raw CNR with independently re-centred script 08 segments. Do not restore the archived CNS files as canonical. `models.tsv` provides hashes and regeneration paths. Scratch CNR paths may not exist in a clone: reconstruct target-only CNR by excluding exact `gene == Antitarget` rows from the verified source, preserve all other rows/columns including zero depth, and check the manifest hash or document serialization-only differences plus exact tabular equality.
- The target mask has 204,706 retained bins. Genomic segment spans interpolate across targets. Near-zero off-target coverage must be explained from upstream alignment/interval handling before requesting padded SNP evidence or WGS-like features.
- Same capture-kit compatibility of model/reference exomes is author-confirmed; this does not establish equivalent alignment/preprocessing. The recovered design is SeqCap EZ Exome v3. Reuse received files; investigate only outstanding compatibility evidence.
- TOV81D has an exact curated pathogenic BRCA2 allele, but historical expression of the wild-type allele prevents an automatic BRCA2-null label. CDK12 disruption, genomic scars, present HR function and drug response are different measurements.
- The local SBS3 sensitivity analysis is a method-stability check. Neither a fitted SBS3 fraction nor current relative FGA is an HRD score.
- No matched donor normals have been established. Report newly found donor normals with identity/consent provenance instead of assuming a public reference is a donor normal.
- The author explicitly approved the 53-allele coordinate-only NCBI query, which is now complete. Reuse the [exact ClinVar snapshot](../../../reports/molecular_extension_2026-09-06/variants/clinvar/README.md): 23 alleles / 29 model observations have direct exact matches. Current ATR/PTEN/BRAF annotations supersede older archived classification strings; no-match records are not benign calls. MEX08 still needs local haplotype, second-hit and functional evidence. TOV2881EP TP53 R156P classification applies to the isolated SNV, not automatically to its combined phased allele.
